# Discover and requests

Discover shows trending titles, popular movies and popular series from your
request manager (Seerr). Search finds anything else. Every title shows
whether it is already in the library, on its way or requested.

## Requesting

Pick a title and choose the quality: standard or 4K. The 4K choice appears
when a 4K server is set up in Seerr. For a series, pick seasons, or leave
them all empty to request every missing season. Seerr decides whether the
request needs approval, exactly as if it were made in Seerr itself.

Admins also find the quality profile and the folder under "Advanced".

## Who requests

Each request is made as your own Seerr user. Wardarr matches users by name.
If a name differs, an admin links the user by hand under
**Requests → Users**. Until then, that person can browse Discover but not
request.

## Managing requests (admins)

**Requests → All requests** starts with everything waiting for approval.
Approve, decline, edit (quality, server, profile, folder) or try a failed
request again. Everyone else sees their own requests under **Requests**.
